# 三仓库项目地图

状态快照：2026-10-11。此页说明产品分工与当前阶段；具体实现和运行命令以各仓库自己的文档与代码为准。仓库可见性是 GitHub 访问设置，不代表服务已上线。

## 三个现有仓库

| 仓库 | GitHub 可见性 | 拥有的内容 | 当前阶段 |
| --- | --- | --- | --- |
| [SekerEdexWebLab](https://github.com/Seker800/SekerEdexWebLab) | 公开，采用 GPLv3 | eDEX Web 前端、视觉合同、复刻系统和现有静态站发布入口 | 前端代码独立；通过公开 HTTP 契约读取内容服务；不再包含内容服务源码 |
| [SekerMinimalWeb](https://github.com/Seker800/SekerMinimalWeb) | 私有 | 极简阅读前端及其独立的视觉、构建与未来发布边界 | 已有可本地预览的首页和栏目视觉样稿；尚未接入内容 API，也没有生产发布入口 |
| [SekerContentApi](https://github.com/Seker800/SekerContentApi) | 私有；迁出的代码保留 GPL-3.0-only 许可 | 内容 API、私有管理后台、SQLite 结构与媒体存储接口 | 代码、测试和本地运行入口已独立；生产服务尚未部署或授权升级 |

私有仓库链接对没有权限的人不可见。**公开仓库、开源许可证、正在生产运行是三个不同概念。**

## 系统关系与事实源

```text
访客 → eDEX Web ──────┐
                     ├─ 只读 /api/v1/content、/api/v1/media/:id → 内容服务
访客 → 极简 Web（规划接入） ┘                                  │
                                         作者 → 私有管理后台 ─┤
                                                             └─ 私有 SQLite 与媒体卷
```

- 作者文章、链接、图片、视频、目录路径、顺序和草稿/发布状态只由内容服务持有。两个前端各自负责界面与路由，只读取已发布内容；不导入后端源码，不连接 SQLite，也不保存管理员凭据。
- eDEX 仓库中的 `examples/blog` 是标明的公开示例，不是作者内容事实源。极简站当前样稿目录和图片也不代表已发布内容。API 故障时不能用任一套样稿冒充真实内容。
- 作者内容修改不需要前端代码提交或构建；前端代码、内容服务程序、作者内容数据分别走各自的验证和发布流程。
- 跨仓库 API 不兼容变更须先设计迁移期并分别验证两个前端。公共契约是 HTTP `/api/v1`，不是共享源码包。

## 管理后台现在能做什么

内容服务的 `/admin` 是独立的本地管理页面：可创建和修改 Markdown 文章、链接，上传图片和视频，切换草稿/发布，并通过数值调整顺序。目录层级通过内容的 `relativePath` 表达；目前没有树状拖拽编辑。后台页面不能直接编辑已上传媒体的路径。后台不是 eDEX 或极简前端的一部分，也不因页面代码存在而自动对外可用；本地访问前必须先配置并启动内容服务。

## 已定边界与待决事项

- 当前 eDEX 站点的根地址和静态对象仍由 eDEX 仓库的发布流程拥有。极简站不得复用其发布脚本或覆盖其对象；内容服务不得借前端发布顺便升级。
- 极简站的内容 API 接入、独立构建和测试环境仍待实施。它能与 eDEX 同时读取同一份已发布内容，且互不覆盖发布物后，才进入多入口方案的下一步。
- 中性选择首页只是未来规划，**不是第四个现有仓库或当前 eDEX 首页改版**。正式域名、路由迁移、回滚和生产部署须单独决策。
- 内容服务生产部署尚未授权；本地 `/admin` 地址拒绝连接通常意味着服务没有启动，不能据此判断后台页面不存在。
