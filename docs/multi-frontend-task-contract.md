# 多前端后续任务合同

状态：`BLOCKED`（北极星已记录；实现和生产路由须由单独任务明确启动）。
本合同只约束后续工作，不是本轮的实施或上线许可。北极星见
[多前端北极星](MULTI_FRONTEND_NORTH_STAR.md)。

## Slice 1 — 独立极简前端

- 目标/范围：单独仓库中的最小静态阅读器，只读取现有公开 API；不复制 `apps/clone`、
  eDEX 素材或作者内容，不改本仓库发布脚本。
- 输入/输出：输入为版本化 API 协议和隔离的测试内容；输出为可单独构建的前端与自动测试。
- 验收：文章、链接、图片、视频、目录和顺序可见；草稿不可见；eDEX 与极简前端同时读取
  同一已发布内容，内容修改不要求重建任一前端。

## Slice 2 — 部署隔离设计

- 目标/范围：明确新前端的站点地址、静态对象所有权、CI、回滚和 CORS origin；
  不改动当前 eDEX 生产根地址或对象。
- 输入/输出：输入为 Slice 1 的独立构建；输出为经审查的独立发布方案和测试环境证据。
- 验收：测试发布与回滚不覆盖 eDEX 文件；API 兼容，两个 origin 各自可读。
  生产目标、凭据和上线动作另行批准。

## Slice 3 — 中性入口页

- 目标/范围：两个前端各自可访问且可回滚后，独立实现仅提供入口的轻量页面；
  不把入口塞入 eDEX 画布，不改变其视觉验收标准。
- 输入/输出：输入为 Slice 2 的隔离证据和作者确认的地址迁移方案；
  输出为有独立发布与回滚方式的入口页。
- 验收：键盘和鼠标均可进入两个前端，直达地址仍可用，eDEX 视觉门禁仍通过。

每阶段完成前不得提前推进下一阶段。内容服务拆仓已由 ADR 0007 单独决策并实施；
后续跨仓库公共代码或 API 破坏性变更仍须另提决策，不能由实现 Agent 默默加入。

## 收口

本合同在上述三个阶段均有测试、部署隔离及回滚证据后标记 `COMPLETED`，再归档为
`docs/archive/` 下的 `ARCHIVED` 合同；若用户只选择其中一阶段实施，其余阶段保持未授权，
不宣称多前端完成。
现阶段待定的是生产域名/路径、极简前端仓库可见性以及入口页迁移时间；这些不妨碍本轮文档
完成，但在任何生产切换前必须由作者确认。
