# eDEX-UI 视觉与交互复刻合同

这份文档定义“一比一复刻”的判定方式。首要目标是在固定参考画布上重现官方默认截图的
构图、比例、颜色、排版、线框、间距和可见状态；运行体验和固定画布缩放在此基础上验收。
不复制上游 Logo、截图文件或其他品牌资产。

## 一比一判定规则

1. 从官方 PNG 的 `(5, 5)` 裁取 1920×1080 基准内容，在相同尺寸生成无浏览器边框截图并叠加比较。
2. 几何结构、主色、文字层级和主要可见状态必须逐项匹配，不能只凭肉眼判断“风格相似”。
3. 每轮保存基准图、实现图、差异图和差异说明；尚未建立自动比较工具前不得宣称一比一完成。
4. 所有桌面尺寸保持同一 16:9 构图；非 16:9 视口只允许等比缩放并留边。
5. 图标和程序化音效产生的不可避免差异必须单独登记，不能悄悄忽略。
6. `blade`、`horizon`、`disrupted` 等其他主题或效果不得进入基准实现；后续只能作为独立增强。

## 必选体验

### 画面组成

- [x] 1920×1080 下，主分区边界和面积比例与裁剪后的官方参考内容一致。
- [x] 1440×900 下显示 1440×810 的完整工作台，并在上下各保留 45 像素背景边。
- [x] 默认 `tron` 的黑色背景、灰蓝主色、弱化文字色和线框明暗关系一致。
- [x] 顶部标签、左侧系统面板、中央终端、右侧网络面板、底部文件系统与 QWERTY 键盘均处于对应位置。
- [x] 中央终端呈现与参考画面相同层级的 `neofetch` 启动状态，用独立 Web 实现重现排版。
- [x] 页面进入后形成固定全屏控制台，不出现传统网页首屏加长列表。
- [x] 中央终端是主舞台，视觉权重大于辅助面板。
- [x] 左右至少各有一组持续活动的遥测或日志模块。
- [x] 底部屏幕键盘具有足够面积，成为设备感的一部分。
- [x] 边框、切角、刻度、网格和留白共同形成统一的设备语言。

### 运行感

- [x] 启动序列展示模块自检与分阶段进入，不只是进度条遮罩。
- [x] 时钟、图表、光标、日志与状态指示器以不同节奏持续活动。
- [x] 页面隐藏时持续动画和采样暂停，恢复后状态连续。
- [x] 不操作时仍能感知系统运行，但不会出现无意义的高频闪烁。

### 输入联动

- [x] 实体键盘按下与屏幕键帽高亮同步。
- [x] 屏幕键盘可以向终端输入字符和控制键。
- [x] 点击文件会产生与终端命令等价的导航行为。
- [x] 操作具有一致的视觉反馈和可关闭的程序化音效。
- [x] 错误、拒绝、成功和扫描至少具有四种可辨识反馈。

### 命令与文件系统

- [x] `help`、`ls`、`cd`、`clear` 和 `theme` 形成最小命令闭环。
- [x] 鼠标路径与命令路径共享同一文件系统状态。

### 可用性与性能

- [x] 核心导航支持键盘，并具有可见焦点。
- [x] `prefers-reduced-motion` 下仍能理解状态变化。
- [x] 音频由用户手势解锁，并可通过持续可见的控制开关声音。
- [x] 桌面目标视口在验证设备上交互阶段保持稳定帧率；测量方法和数字写入报告。
- [x] 移动端提供专门的终端模式，不把桌面三栏和完整键盘等比缩小。

## 明确不算完成

- 只有一张与 eDEX-UI 相似的静态页面。
- CPU、内存、文件树和日志都是无法产生行为的装饰。
- 只支持命令输入，鼠标用户无法完成主要路径。
- 为了效果强制播放声音、捕获键盘或忽略减少动态效果设置。
- 用录屏代替可操作原型。

## 证据要求

每个 Slice 保存：

1. 裁剪后的 1920×1080 基准图、实现图与差异图。
2. 1920×1080 和 1440×900 等比缩放状态的截图或短录屏。
3. 可执行的验证命令和结果。
4. 已知偏差、测量结果及其原因。
5. 性能采样环境与数据。
6. 是否继续、调整或终止该方向的结论。

当前交互证据由 `npm run app:verify` 生成到 `artifacts/app-verification/report.json`。2026-09-18
的 Chromium 无头采样在完整动态工作台上记录 30 帧、约 489 ms、约 61.3 FPS；同一门禁执行
实体键盘、鼠标、桌面触摸键盘、声音开关、主题拒绝、文件系统联动、减少动态效果与
390×844 移动终端模式。

## 有意扩展：媒体显现

上游 eDEX-UI 2.2 没有图片浏览器或图片解码动画。项目媒体查看器采用自有的 10×6 图片裁片，
在图片真实解码完成后，仅在 `contain` 后的实际图片边界内以 `tron.signal` 蓝色单色状态重建画面，
再按固定扫描顺序逐块恢复原始色彩；底层完整图片在动画结束前保持不可见。它复用上游文件列表
分阶段显现、短促亮度变化与
约半秒过渡的动效语言，但不宣称为上游原生实现或真实解码进度。完整动画至少持续 534 ms，避免
缓存命中时内容瞬间出现；加载失败保持明确错误状态，快速切图会取消过期显现，
`prefers-reduced-motion` 下跳过遮罩动画并直接显示已解码图片。
