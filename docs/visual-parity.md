# eDEX-UI 视觉与交互复刻合同

这份文档定义“一比一复刻”的判定方式。首要目标是在固定参考画布上重现官方默认截图的
构图、比例、颜色、排版、线框、间距和可见状态；运行体验和响应式适配在此基础上验收。
不复制上游 Logo、字体文件、截图文件或其他品牌资产，不能成为放宽视觉差异的理由。

## 一比一判定规则

1. 在 1934×1094 参考画布下生成无浏览器边框截图，与官方参考图叠加比较。
2. 几何结构、主色、文字层级和主要可见状态必须逐项匹配，不能只凭肉眼判断“风格相似”。
3. 每轮保存基准图、实现图、差异图和差异说明；尚未建立自动比较工具前不得宣称一比一完成。
4. 1920×1080 保持同一构图并只做必要缩放；1440×900 允许受控重排，但不得变成普通网页。
5. 原创字体、图标和程序化音效产生的不可避免差异必须单独登记，不能悄悄忽略。
6. `blade`、`horizon`、`disrupted` 等其他主题或效果不得进入基准实现；后续只能作为独立增强。

## 必选体验

### 画面组成

- [ ] 1934×1094 下，主分区边界和面积比例与官方参考图一致。
- [ ] 默认 `tron` 的黑色背景、灰蓝主色、弱化文字色和线框明暗关系一致。
- [ ] 顶部标签、左侧系统面板、中央终端、右侧网络面板、底部文件系统与 QWERTY 键盘均处于对应位置。
- [ ] 中央终端呈现与参考画面相同层级的 `neofetch` 启动状态，用独立 Web 实现重现排版。
- [ ] 页面进入后形成固定全屏控制台，不出现传统网页首屏加长列表。
- [ ] 中央主舞台承担终端和内容查看器，视觉权重大于辅助面板。
- [ ] 左右至少各有一组持续活动的遥测或日志模块。
- [ ] 底部屏幕键盘具有足够面积，成为设备感的一部分。
- [ ] 边框、切角、刻度、网格和留白共同形成统一的设备语言。

### 运行感

- [ ] 启动序列展示模块自检与分阶段进入，不只是进度条遮罩。
- [ ] 时钟、图表、光标、日志与状态指示器以不同节奏持续活动。
- [ ] 页面隐藏时持续动画和采样暂停，恢复后状态连续。
- [ ] 不操作时仍能感知系统运行，但不会出现无意义的高频闪烁。

### 输入联动

- [ ] 实体键盘按下与屏幕键帽高亮同步。
- [ ] 屏幕键盘可以向终端输入字符和控制键。
- [ ] 点击文件会产生与终端命令等价的导航行为。
- [ ] 操作具有一致的视觉反馈和可关闭的程序化音效。
- [ ] 错误、拒绝、成功和扫描至少具有四种可辨识反馈。

### 内容替换

- [ ] `help`、`ls`、`cd`、`open`、`clear` 和 `theme` 形成最小命令闭环。
- [ ] 可以在主舞台阅读一篇完整文章并返回终端状态。
- [ ] 可以浏览一组摄影作品且不会跳出控制台体验。
- [ ] 可以打开一个设计案例并展示图像与说明。
- [ ] 鼠标路径与命令路径指向同一内容对象。

### 可用性与性能

- [ ] 核心导航支持键盘，并具有可见焦点。
- [ ] `prefers-reduced-motion` 下仍能理解状态变化。
- [ ] 音频默认静音，解锁后可以再次静音。
- [ ] 桌面目标视口在验证设备上交互阶段保持稳定帧率；测量方法和数字写入报告。
- [ ] 移动端提供专门的终端/内容模式，不把桌面三栏和完整键盘等比缩小。

## 明确不算完成

- 只有一张与 eDEX-UI 相似的静态页面。
- CPU、内存、文件树和日志都是无法产生行为的装饰。
- 点击导航后进入普通长页面，控制台只是首页皮肤。
- 只支持命令输入，鼠标用户无法完成主要路径。
- 为了效果强制播放声音、捕获键盘或忽略减少动态效果设置。
- 用录屏代替可操作原型。
