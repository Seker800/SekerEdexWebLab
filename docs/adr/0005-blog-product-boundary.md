# ADR 0005: 将指挥舱复刻限定为博客入口体验

- Status: Accepted
- Date: 2026-09-18

## Context

Phase 0 已经证明 eDEX-UI 2.2 的 `tron` 指挥舱可以在浏览器中高保真实现，并完成启动、声音、终端、文件系统、键盘和响应式门禁。产品的长期目标现明确为个人技术博客。继续补齐真实 PTY、主机系统监控、本地磁盘访问和完整桌面设置，会增加安全、部署和维护成本，却不能改善文章的发现、阅读和分享。

固定 1920×1080 画布适合作为入口体验，不适合作为文章正文容器。文章需要语义化 HTML、稳定 URL、静态输出、SEO、RSS、可访问性和移动端阅读布局。

## Decision

1. `apps/clone` 保持为冻结的参考实现、视觉基线和可选指挥舱入口，不在原地改造成博客。
2. 博客建立独立应用边界，采用 Astro 静态输出和 Markdown/MDX 内容集合。
3. 博客复用 `tron` 的视觉语言和类型化导航思想；不继承固定画布、模拟系统数据、完整屏幕键盘或桌面 shell 目标。
4. 终端降级为安全的博客导航与搜索入口，文件面板降级为内容浏览入口。
5. 遥测只展示真实站点、构建或当前浏览器会话数据。
6. 现有 eDEX 视觉合同和比较阈值继续只约束复刻应用；博客使用独立验收合同。

## Kept capabilities

- `tron` 色彩、线框、排版层级和启动氛围。
- 可关闭声音、reduced motion、键盘操作和移动端降级。
- 类型化命令、统一导航事实、统一调度和可销毁渲染器。
- 文件面板作为文章、标签和项目入口。

## Removed from the product roadmap

- 真实 PTY、任意 shell、`curses`、终端鼠标协议和多进程标签。
- CPU 温度、进程表、内存、磁盘、GeoIP 和活动连接等主机监控。
- 本地文件系统、块设备、文件编辑和文件监听。
- 多键盘布局、密码模式、开发工具快捷键和完整设置文件编辑器。
- 内建文档/媒体查看器、主题市场和任意 CSS 注入。

## Consequences

- 博客内容可以独立索引、直达和渐进增强。
- 复刻研究成果和证据链不会被产品改版破坏。
- 仓库将暂时包含复刻工具、参考应用和博客应用三个边界，需要在维护文档中明确命令与发布目标。
- 共享样式必须通过 token 或窄接口复用，禁止把复刻应用的全局 CSS 导入博客。
