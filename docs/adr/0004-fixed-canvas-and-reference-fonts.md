# ADR 0004: 固定 16:9 画布

- Status: Accepted
- Date: 2026-09-16

## Context

原版 eDEX-UI 以全屏 16:9 为主要运行环境，并在窗口模式下主动维持 16:9。官方参考 PNG
尺寸为 1934×1094，但 alpha 大于 127 的不透明 UI 区域从 `(5, 5)` 开始，正好是
1920×1080。自由重排会改变面板比例，使一比一复刻失去稳定基准。

## Decision

- 桌面 Shell 固定使用 1920×1080、16:9 逻辑画布。
- 非 16:9 桌面视口通过外层容器等比缩放、居中并留背景边；不重排、不裁切、不拉伸。
- 移动端在桌面复刻完成后另行定义模式，不参与 Phase 0 桌面基准。

## Consequences

- 1920×1080 是唯一几何事实，其他桌面尺寸没有第二套面板布局。
- 1440×900 视口显示 1440×810 工作台，并在上下各保留 45 像素背景边。
- 移动体验不会通过压缩或破坏桌面布局仓促实现。
