# ADR 0002: 锁定默认 Tron 官方截图

- Status: Accepted
- Date: 2026-09-16

## Context

eDEX-UI 自带多种主题和布局变体。若同时参考多个版本，颜色、面板比例、键盘布局和故障效果
会在实现过程中漂移，最终只能得到泛化的“科幻终端风格”，无法判断是否真正完成复刻。

## Decision

- Phase 0 唯一视觉基准是上游 README 的默认截图：eDEX-UI 2.2、默认 `tron` 主题、
  QWERTY 键盘，并在中央终端运行 `neofetch`。
- 官方 PNG 为 1934×1094；裁取从 `(5, 5)` 开始的 1920×1080 完全不透明内容作为一比一
  视觉基准。
- 一比一包括布局、比例、颜色、排版层级、线框、间距和画面状态，也包括时钟、图表、终端、
  文件系统和键盘形成的运行联动。
- 参考截图只通过固定 commit 链接和 SHA-256 标识，不把第三方截图文件提交到仓库。
- 其他主题和 `disrupted` 效果推迟到默认 Tron 基准通过后，以独立增强处理。

## Consequences

- 首个实现不建设通用主题系统，所有视觉判断都有唯一参照。
- 每轮视觉工作必须产生同尺寸截图和差异证据，不能以主观相似代替验收。
- 为适配 Web 可重新实现图标、声音和行为，但所有可见偏差都要明确记录。
