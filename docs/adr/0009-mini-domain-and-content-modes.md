# ADR 0009 — 极简子域名、启动入口与显式内容模式

日期：2026-10-18。状态：已采纳，依据作者本轮明确选择。

作者选择 `mini.seker.wang`，保留 `www.seker.wang` 的 eDEX 初始页，在启动门增加极简入口。
不另建中性选择页，不改变已启动工作台的固定画布与视觉基准。入口是可键盘、鼠标和触摸操作的
普通 HTTPS 链接；声音控制和初始化流程保持独立，链接随中英文选择显示。

两个仓库各自维护同格式 `site.config.json`：`contentMode: sample | api` 和公开 `contentApiOrigin`。
当前无生产后端时显式选择 sample；该模式只包含许可明确的样稿并标注样稿状态。
api 模式须配置有效 origin，生产要求公开 HTTPS 域名；运行时失败、空数据、格式错误不得回退样稿。
配置来源选择与接口故障分开。构建环境仍只通过白名单公开配置，绝不接触私有数据库和作者原件。

这部分替代 ADR 0006 中生产构建始终必须是 runtime 的限制：作者现已明确要求可发布样稿模式。
API 模式的安全与错误边界不变。前端切换模式要重新构建与发布；API 模式下日常编辑内容不重建前端。

极简站拥有独立北京区 OSS `seker-mini-web` 和 CDN `mini.seker.wang`；eDEX 继续拥有
`seker-edex-web` 和原有站点。各自仓库、构建、CI、版本标记、发布与回滚独立。
本轮“帮我弄好”的授权覆盖上述静态站、域名和 HTTPS 配置，不扩展为内容服务部署或数据迁移。
先核验极简地址可访问，再发布 eDEX 的链接。两个前端对公开 API 的客户端验证不能替代后端生产验收。

验收：双浏览器鼠标/键盘/触摸入口；两种模式的构建与异常路径；原 eDEX 全套门禁；
各自精确提交的 GitHub CI；各自 HTTPS 首页与版本标记。冻结目标、阈值和视觉判定器不变。
