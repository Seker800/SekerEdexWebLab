# ADR 0001: eDEX-UI 参考与许可证边界

- Status: Accepted
- Date: 2026-09-16

## Context

项目希望复刻 eDEX-UI 的 Web 视觉和交互体验。上游代码使用 GPLv3，且包含由不同作者提供的
音效、字体、图标和 vendor 代码。项目维护者愿意将程序开源，但个人文章、摄影和设计作品
仍需保持独立版权。

## Decision

- 项目程序使用 GPL-3.0-only。
- 当前先通过行为观察和独立实现验证可行性，不预先复制上游代码或素材。
- 后续允许在有明确工程收益时复用 GPL 代码，但必须按研究文档记录文件级来源。
- 原音效、Logo、截图和字体默认不复用；程序化音效和原创视觉资产优先。
- 个人内容与程序分目录，并由内容目录单独声明许可证。
- 项目名称、文案和发布页面明确说明这是非官方实现。

## Consequences

- 未来可以合法接收 GPL 上游实现，但整个衍生程序必须继续提供 GPL 对应源码。
- 视觉复刻不会因为许可证方便而退化为直接运行旧 Electron 代码。
- 个人内容不会因程序采用 GPL 而被误解为允许自由复制。
- 每次引入第三方素材都会产生显式审查成本。
