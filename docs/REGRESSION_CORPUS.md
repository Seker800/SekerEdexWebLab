# 功能与恢复回归语料

视觉候选的逐像素接受/拒绝记录仍见 [VISUAL_REGRESSION_CORPUS](VISUAL_REGRESSION_CORPUS.md)。
本页登记功能反例；不得用放宽冻结阈值、移除断言或改写运行证据来关闭反例。

## 2026-10-18 全面检查

| 反例 | 原行为 | 修复契约 | 可执行回归 |
| --- | --- | --- | --- |
| 内容 API 停在响应头或正文 | 页面等待无上限 | 完整请求八秒截止，取消底层读取并清理定时器 | `tests/content-api-client.test.ts`、`tests/request-lifecycle.test.ts` |
| API 故障时打开文章直链 | 空白或空目录，原文章地址被改成根目录 | 显示加载/错误/空状态；保留初始地址；手动重载后恢复文章，绝不回退示例 | `scripts/verify-content-client.ts` |
| 目录超过首屏容量 | 网格禁止滚动，末尾内容无法用鼠标到达 | 运行模式内部滚动，最末文件不与页脚重叠；固定参考构图不变 | 同上，80 篇文章与真实滚轮输入 |
| 图片解码中关闭 | 隐藏后仍启动显现，零尺寸导致异常 | 共享弹层失活通知使过期解码结果不能启动渲染 | `scripts/verify-resilience.ts`，延迟真实图片解码 |
| 关闭文章内视频 | 隐藏内容没有统一暂停 | 隐藏或切换视图时暂停嵌入媒体，视频查看器释放来源 | 同上，真实 DOM 媒体生命周期 |
| Tab 离开模态内容 | 焦点可能离开弹层 | 首末可聚焦控件之间循环，Escape 关闭 | 同上 |
| 手机文件视图关闭媒体 | 试图聚焦隐藏终端，焦点丢失 | 回到当前可见文件区 | 同上，390×844 |
| 浏览器拒绝 localStorage 属性访问 | 语言容错没有包住属性读取，启动报错 | 当次访问仍能启动和切换语言 | 同上，抛出 SecurityError 的存储 getter |
| 往返缓存页面隐藏 | 销毁所有监听器，恢复后控件失效 | 只在非缓存离开时销毁，缓存状态保留 | 同上，persisted PageTransitionEvent；不据此声称浏览器一定采用缓存 |
| 中文输入法选词时回车/方向键 | 草稿被命令提交或历史覆盖 | composition 期间不执行终端控制与提交 | 同上，组合事件与真实表单提交 |
| 启动日志挂起后跳过 | 画面完成但启动 Promise 不结束，重启按钮禁用 | 跳过取消网络和等待，立即恢复控制 | 同上，拦截启动日志请求，Chromium 与 WebKit |
| 标题 A、A、A-2 | 生成重复锚点 a-2 | 所有已分配 ID 参与去重 | `tests/blog-content.test.ts` |
| 文章中的失效本地链接 | 虽标记禁用仍有 `href="#"`，点击使阅读器跳回根目录 | 无效引用不输出导航地址 | 同上 |
| 切换中文后的导航项 | 返回上级、显示磁盘仍是英文 | 只翻译界面标签，内部文件操作名保持稳定 | `scripts/verify-locales.ts` |
| 自定义自动修复写入路径 | 可指定比较器、采集器、脚本或 CI | 整个控制器源码、脚本、CI 与根构建清单均为受保护路径 | `tests/contract.test.ts`，十类原先被接受的路径 |

`npm run verify` 包含全部回归。功能报告、桌面与移动截图由工具生成到 `artifacts`；
测试服务只使用公开样例和合成数据，不读取生产后台或数据库。
